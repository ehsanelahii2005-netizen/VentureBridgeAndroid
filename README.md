# VentureBridge Android (Demo)

نمونه اولیه اندرویدی فارسی و راست‌چین برای نمایش ایده VentureBridge.

## امکانات فعلی
- داشبورد آماری نمایشی
- فهرست و جست‌وجوی فرصت‌های سرمایه‌گذاری
- صفحه جزئیات فرصت
- فهرست شرکت‌ها
- شبکه نمونه سرمایه‌گذاران (VC، CVC، بانک و صندوق)
- مرکز ارزیابی نمایشی
- فرم ثبت آزمایشی فرصت

## ساخت APK بدون نصب Android Studio (با GitHub Actions)
1. وارد GitHub شوید و یک حساب کاربری بسازید یا وارد حساب خود شوید.
2. یک مخزن جدید (New repository) بسازید؛ نام پیشنهادی `VentureBridgeAndroid` است.
3. فایل ZIP پروژه را روی کامپیوتر از حالت فشرده خارج کنید.
4. وارد مخزن شوید و از گزینه **Add file > Upload files** تمام محتویات پوشه `VentureBridgeAndroid` را بارگذاری کنید؛ خود پوشه مادر را داخل مخزن تو در تو نکنید. سپس **Commit changes** را بزنید.
5. از بالای مخزن وارد زبانه **Actions** شوید.
6. در فهرست سمت چپ، **Build VentureBridge APK** را انتخاب کنید.
7. روی **Run workflow** و سپس دکمه سبز **Run workflow** کلیک کنید.
8. پس از پایان موفقیت‌آمیز اجرا (علامت سبز)، همان اجرای workflow را باز کنید.
9. در پایین صفحه، از بخش **Artifacts** فایل `VentureBridge-debug-APK` را دانلود کنید.
10. ZIP دانلودشده را باز کنید و فایل `app-debug.apk` را به گوشی منتقل و نصب کنید.

> برای این روش Android Studio لازم نیست؛ اما بارگذاری پروژه و اجرای workflow به حساب GitHub و اتصال اینترنت نیاز دارد. فایل خروجی debug برای نصب و آزمایش است و نسخه انتشار امضاشده برای انتشار عمومی در فروشگاه‌ها نیست.

## نکته مهم
تمام شرکت‌ها، سرمایه‌گذاران، آمار، امتیازها و فرصت‌های داخل برنامه ساختگی و صرفاً نمایشی هستند. نسخه فعلی سرور، ثبت‌نام واقعی، احراز هویت، پایگاه داده ابری، بارگذاری اسناد یا عملیات مالی ندارد. داده فرم نیز فقط در وضعیت همان اجرای برنامه نمایش داده می‌شود.
